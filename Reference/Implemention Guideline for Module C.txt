1. Objective: implement, train, tune, and benchmark a deep learning model on the dataset.

Primary script location: skeleton for model.py (in project root), with pretrained.py for transfer learning
Serialized models folder: models/deep/
Exported figures folder: figures/


2. Shared infrastructure integration

Do not write custom split logic or custom metric functions. All evaluation 
must use the shared infrastructure:

- config.py: Import SEED, CLASS_NAMES, NUM_CLASSES, IMAGE_SIZE, INPUT_SHAPE, RESULTS_PATH, and seed_everything. Call seed_everything(SEED) at script start.
- metrics.py: Use compute_metrics(y_true, y_pred) for all evaluations. Convert model logits to predicted class indices via torch.argmax(logits, dim=1).cpu().numpy() before passing.
- preprocess.py:
    Use dummy_batch(batch_size, modality="deep") to build and test pipelines immediately (channels-first tensors).
    Swap to real image loading, torchvision transforms, or PyTorch Dataset/DataLoader once Module A completes.
- results.csv: Append every model run with columns: model_name,module,config,balanced_accuracy,accuracy,macro_f1,runtime_s (set module="C").


3. Workflow

Phase 1: Immediate Development (Dummy Data)
1. Verify environment: run "pip install -r requirements.txt" (PyTorch 2.0+ and torchvision 0.15+).
2. Open model.py in the root directory.
3. Implement build_model() with the chosen custom convolutional network architecture.
4. Test training execution, loss curve tracking, early stopping, and evaluation logging using dummy_batch(batch_size=32, modality="deep").
5. Verify that results.csv records test rows with module="C" and figures/ saves training curves and confusion matrix heatmaps.

Phase 2: Transition to Real Data (When Module A Completes)
1. Integrate data pipeline with Module A image transforms, PyTorch Dataset, and DataLoader.
2. Address 58 to 1 class imbalance by computing balanced class weights on the training split and passing them to nn.CrossEntropyLoss(weight=weights_tensor).
3. Train the custom CNN on the train split and evaluate on the val split. Record genuine wall-clock training time.
4. Run hyperparameter sweeps (learning rates, batch sizes, dropout rates, optimizers). Save best weights (.pt) to models/deep/.
5. Generate and export training and validation loss/accuracy curves and confusion matrix heatmaps to figures/.
6. Use pretrained.py to fine-tune the EfficientNetB0 backbone specified in the proposal.
7. The test split is held out and opened once for final reporting.


4. Implementation notes

- Class imbalance handling: Compute class weights using sklearn.utils.class_weight.compute_class_weight("balanced", classes=np.arange(NUM_CLASSES), y=y_train_indices). Pass tensor weights to torch.nn.CrossEntropyLoss(weight=weights_tensor).
- Final layer and loss: Output raw logits with shape (batch_size, NUM_CLASSES). Pair with nn.CrossEntropyLoss for integer targets.
- Metric integration: compute_metrics requires 1D arrays of integer indices or string labels. Convert PyTorch predictions with torch.argmax(logits, dim=1).cpu().numpy() before evaluation.
- Overfitting controls: Include Dropout (rates 0.2 to 0.5), BatchNorm2d, and early stopping on validation loss.
- Checkpointing: Save model state dictionaries to models/deep/ (e.g. models/deep/best_model.pt) using torch.save(model.state_dict(), path).
- Deterministic execution: Call seed_everything(SEED) from config.py before model construction.
